Overview

FreeChain puts one OpenAI-compatible endpoint in front of an ordered chain of model providers. Your apps point at this server with a single fixed key; it holds the real provider credentials and walks the chain until something answers.

HTTP error legend

“Ready” means configured, not live-tested. Cooling applies to one candidate so another configured candidate can answer.

400 / 422 · request rejected
The provider says the request itself is invalid or unsupported. FreeChain stops instead of spending every candidate. An OmniRoute pool-diagnostics 400 is the documented exception and falls through.
401 / 403 · authentication or permission
The candidate could not use its credentials or account permission. It cools and the next candidate is tried; correct the affected key or account.
404 · endpoint or model missing
The provider does not recognise the configured endpoint or model. It cools while the chain continues; update the matching provider or chain configuration.
408 / network · timeout or unreachable
The provider did not answer before the timeout, or a connection failed. That candidate cools and FreeChain advances to the next one.
429 · rate limited
The provider is temporarily limiting that candidate. FreeChain honours Retry-After when supplied, otherwise uses the configured cooldown, then tries it again later.
5xx · provider failure
The provider reported a server-side error. FreeChain cools that candidate and continues down the configured chain.

Local API keys

One fixed key for every app that talks to FreeChain. Give this to your tools instead of a provider key — the real credentials never leave this machine, and revoking here cuts off every app at once without touching any provider account.

Local API key

Required on every request to /v1/*.

Rotating takes effect immediately. Every app using the old key stops working until you paste the new one.

Log policy
What the journal is allowed to keep.

            

              By default FreeChain writes metadata only: which app called, which provider
              answered, how long it took. Everything below turns some part of the actual traffic
              into a stored record on this machine. Each one is off until you turn it on, and the
              Logs page always states the policy currently in force.
