Overview

FreeChain puts one OpenAI-compatible endpoint in front of an ordered chain of model providers. Your apps point at this server with a single fixed key; it holds the real provider credentials and walks the chain until something answers.

Access key

One fixed key for every app that talks to FreeChain. Give this to your tools instead of a provider key — the real credentials never leave this machine, and revoking here cuts off every app at once without touching any provider account.

Local API key

Required on every request to /v1/*.

Rotating takes effect immediately. Every app using the old key stops working until you paste the new one.

Model sources

        

          Each source has numbered account slots. Rate limits are per account, so adding a second
          slot means a 429 retries on the next account before the chain downgrades to a weaker
          model. Keys are written to .env on this machine and are never
          sent back to this page in full.
